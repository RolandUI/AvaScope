A LITTLE DEEPER

More ways to work.

A few more capabilities.
Open one for a closer look.

INSPECTUnderstand a layout

See an element’s size, position and surrounding space. Help your agent investigate why a label gets cut off or a button sits in the wrong place.

Layout inspection in the guide ↗
INSPECTFind available actions

Discover the actions, routes and shortcuts available in a window. Your agent can work out where to go and what it can do next, with unavailable areas called out.

Action discovery in the guide ↗
INTERACTWork with tables

Read rows and columns from supported tables, then select, edit or sort with the right permissions. Check the resulting state after each action.

Table workflows in the guide ↗
EXPERIMENTTry a temporary change

Try supported changes to text, spacing or styling in a running app. Compare the result and reset the experiment. Source files stay untouched.

Runtime changes in the guide ↗
CHECKLook at keyboard focus

Inspect which element has focus and explore keyboard navigation. Keep predicted movement separate from what an actual, explicitly requested probe observes.

Focus inspection in the guide ↗
REVIEWKeep the evidence

Collect screenshots, step results and reports for a workflow. Review what passed, what failed and what could not be verified, with local privacy and retention controls.

Evidence in the guide ↗
