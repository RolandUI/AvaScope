# AvaScope Brand Assets

The AvaScope identity uses the selected `Atomic A` concept: a geometric `A` constructed from connected inspection nodes, with a focused teal core.

## Files

- `avascope-logo.png`: horizontal lockup for light backgrounds.
- `avascope-logo-dark.png`: horizontal lockup for dark backgrounds.
- `avascope-icon.png`: standalone icon for light backgrounds.
- `avascope-icon-dark.png`: standalone icon for dark backgrounds.
- `avascope.ico`: multi-resolution Windows setup and application-list icon.
- `brand-assets.json`: dimensions, purposes, and SHA-256 digests for the deterministic exports.

Use the horizontal lockup where the AvaScope name should be visible. Use the standalone icon only where space is constrained or the product name is already present.

## Provenance

The concept and final artwork were created for AvaScope on 2026-07-28 using OpenAI image generation, then processed into transparent repository assets. The dark variants are deterministic color adaptations of the same geometry. No third-party logo or stock artwork is included.
